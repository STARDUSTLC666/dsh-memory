# dsh-memory 第八轮阶段性实验与工程交付报告

本轮形成默认关闭、可审核的 D1 候选，并获得新的受控任务收益证据。**建议进入代码审查；不建议直接生产发布。** 原始 D0、原生 B、D1 的实现与响应适配器不同，本文不把历史 D0 成绩算成 D1 的成绩，也不把本轮称为完整 RSI。

## 冻结与证据边界

- 第七轮 ZIP SHA256 `55deba7fcd2eb4e87abe31b0ab12f7ed797b3195f882aa0c342fb154edd7b906`；11,725 项逐文件哈希和 CRC 全量复核。原始成绩、真值与轨迹未改。
- 研究基座 `e683a4259d9264cb7438c34920fe1efa79e5105c`，D1 源码与参数在模型运行前冻结。模型、提示词、评分器、240 检索估算预算、120 单条检索估算预算、1200 交付估算预算和 4096 公共 tokenizer 代理上限均固定。
- 最小审查分支从最新上游 `97e220edff6235dbe60b67f31bc7e7f018998116` 建立，只移植交付模块、MCP 开关、必要测试与文档。D1 模块与研究版逐字节相同；24 份已用输入在主干上的 B 选择/正文与 D1 完整响应均一致。这是工程兼容证据，不是第二份独立泛化实验。
- 所有 Memory 与 DSH profile 位于 E 盘隔离目录。未操作生产 Memory、更新正式插件、提交上游 PR 或允许模型批准上线。

## 新实验

24 个新任务情境 × 2 次重复 × A/B/D1 = **144 次有效模型实验**，3 个任务家族，每家族 8 个共用场景结构。另有 3 次开发 smoke、27 次成功的零 API 历史会话写入，以及保存的失败尝试和最新主干 DSH 工程会话。不能把 48 次调用或 24 个模板变体解释成 48 或 24 个完全独立仓库缺陷。

|---|---|---|---|---|

D1 对 B 为 **16 胜、3 负、29 平，净增 13 次成功（27.08 个百分点）**；按每个任务两次重复的平均成绩汇总为 11 胜、3 负、10 平。B 两轮分别 14/24、13/24，D1 两轮均 20/24；任务内完全稳定成功 B=11/24、D1=18/24。HTTP 仅净增 1 次，不能推断各领域都有同样收益。

24 个任务聚类的描述性重采样区间为 [8.33%, 45.83%]，但家族只有 3 个且场景模板共享；不宣称广泛统计显著性、无退化或模型训练数据隔离。服务端不支持本次 serializer 的采样 seed，固定的是数据与执行顺序，而非模型内部随机种子。

## 源码级发现与最小修正

原生检索包在 `MdCGOS.recall` 按预算和单条限额选取/截取正文；多个节点时，后续节点的重要修订或撤回条款可能被截去。第五至七轮还存在实验桥的前缀截断与 JSON `source_document` 投影，这些不是本轮原生 B 的等价路径。

D0 两个独立不变量反例证实：原生不适用条件未完整交付，以及局部片段未明确标记不完整。D1 保留原生适用/排除条件、时间、来源、版本与验证状态；不投影任意 JSON；为原文保留哈希和字符区间；对截断、遗漏、预算溢出或权限变化显式返回 INCOMPLETE。预算覆盖序列化响应的项目估算值，不声称等于实际模型计费 Token。

主实验中完整原文的交付由 B 的 42/60 源实例升至 D1 的 54/60。11 次配对胜利与恢复被截断的当前修订/冲突证据相符；4 次胜利中 B 已有正确事实，存在元数据呈现与 Agent 采用差异，不能全部归为截断；另 1 次虽然评分通过，却违反 INCOMPLETE 处理约束。逐案例报告保留这些区别。

白名单交付没有复制所有原生诊断字段（例如 consistency 的完整 verdict/reason）。因此这些相同事实案例还包含警告呈现差异，本轮没有证明所有被省略的诊断都不影响信任决策；保留原生 verification_state 与 qualification 不能当作全字段等价性证明。这个边界需在审查和后续独立消融中核实，不能将全部收益归因于取回事实。

## 不能隐藏的失败

- D1 的 3 次配对退化全部在 HTTP：两次完整规则已交付，但提交的状态数组与正确规则/其自身解释不一致；一次已保留明确过期说明，仍提交 ANSWER。
- 6 次长来源返回 INCOMPLETE，其中 5 次安全 DEFER 造成完成失败；1 次 Agent 无视 INCOMPLETE，提交了能通过原评分的答案。**40/48 原始成绩不变；同时满足本轮显式 INCOMPLETE 规则的成功最多 39/48。** 此补充审计不是事后修改主评分。
- 默认关闭反思；本轮反思次数为 0。未实现 G、预测控制器、JEPA 或自我演化。

## 工程裁决

研究基座 Memory 模块回归 329/329、3 项原始私有语料 SKIP；并发专项 12 个配置共 144/144 次模块执行，含不同并发度/随机顺序。主干审查基座 335/335、4 项明确 SKIP；TypeScript、权限 MCP、公开全文落盘/派生库、Windows/Linux 专项、重启换代和真实 DSH 工程检查见回归报告。通过、SKIP、未测试严格分列。

三项历史私有测试缺少原始数据库/图；最新主干增加一项依赖同一私有库的 SKIP。公开替代仅验证功能，不替代 4355 节点/2948 边的原始语料验收。发布仍受这些缺口、Agent 无视证据状态及有限任务分布约束。

全仓文档行号门禁仍 FAIL：统一构建条件后，干净上游与候选均有相同 142 条红锚，新增 0。未改基线或 allowlist，未伪称全部仓库门禁全绿；与本轮模块测试通过分列。

保留 D1 作为默认关闭的审查候选，允许人工审查与进一步验证；不宣布生产就绪。下一阶段优先验证调用端能否可靠执行 INCOMPLETE/过期处理，并扩展真实任务与私有语料验收；预测式 Memory-RSI 的前置条件仍未满足。
