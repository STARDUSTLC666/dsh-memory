原摘要“交付文本+10.17%”实际指 tokenizer 计量的交付 Token：19768→21778（+10.168%）；字符62822→74568（+18.697%）。不能混用字符数和模型Token。

G未缓存输入+输出下降3.678%，但未缓存输入增加1.8845%；输出减少21.371%，请求100→96，缓存读减少11.17%。因此总数下降主要伴随更短输出和较少调用，不能解释为交付压缩成功或缓存命中改善。各项成本仍受模型随机性、不同请求前缀和共享缓存状态影响。

历史 diagnostic latency_ms 是内层 recall+组装，排除了解释器/tokenizer import；tool receipt 时间还含桥接启动，整次 DSH 时间包括 API 和执行调度。历史未记录组装单项、真实原生 MCP 传输或账单币种成本，不能补造。

新增只读事后组装微基准先验证48个D/G响应逐字节匹配旧档，再在24任务上交替20轮、每组480次：D P50/P95=1.005/2.009ms，G=1.833/3.270ms。包含授权get，排除检索/import/tokenizer加载/进程启动。共享主机运行，不是历史时延、不增加独立任务数、不调G参数，也不等于推理或MCP传输成本。
