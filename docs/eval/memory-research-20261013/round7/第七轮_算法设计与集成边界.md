# D 审计与 S2 最小实验实现

历史 B 是两次前缀截断的实验桥接，D 从授权原文投影 source_document、按查询保留窗口，候选检索/RRF顺序未变，原始记忆未修改。该B是明确的历史实验基线，不等于所有原生插件交付路径都同样截断；原生Agent可能通过get另取正文，而本受控任务没有该恢复工具。

D的源码级边界：截断会损失窗口尾部条件；交付compact字段未完整保留non_applicable_conditions/verification_basis；trace.context可能覆盖原生条件；看不到完整来源不一定显式INCOMPLETE。第六轮long_history/exclusion败例印证其中两个风险。不把D称为所有必要条件完整性已经证明的产品方案。

S2独立模块evidence_preserving.py只做授权节点交付，不改召回/RRF/权限/原文；不写新权威库。

1. from_recall对原生已选ID再次Secure.get。不可见则INCOMPLETE空包，不泄露不可见内容。
2. 已知trace schema投影原始source_document，普通正文或未知JSON保留整个原文。S1曾把任何同名source_document键都视为trace，可能丢外层例外；先用两个失败测试复现，再将识别收紧至已知必需字段与允许字段。S2不是以测试答案选事实。
3. 原文全文与source_sha256、稳定ID共同交付；条件与不适用条件、来源、验证状态/依据、有效期、版本、必要comment白名单保留。trace.context记录为recorded_scope，不能覆盖原生applicability。condition_space.time_window语义为观测窗口，不冒充有效期。
4. 同ID相同内容去重，同ID内容/元数据冲突则空包退让；128记录/100万字符资源限制。凭据类metadata键拒绝交付；这不是对任意正文的全面DLP保证。
5. 对整个序列化工具结果计预算。默认项目est_tokens，可注入模型tokenizer。超预算不静默截断，返回空pack/INCOMPLETE；低于控制信封最小预算显式ValueError。COMPLETE_SOURCE_BUNDLE只代表选中来源齐全，不代表检索充分、事实真或任务可解。
6. 诊断只记录ID、哈希、跨度、预算、required_tokens、原因与实际交付ID；正文仅存在隔离实验运行记录。反思关闭。

原生mdcg_recall新增preserve_evidence严格bool、evidence_budget_tokens独立可选预算；默认false返回原始接口结果。只在实验profile显式打开，现有TypeScript调用转发到既有MCP，不修改生产插件自动上下文钩子。关闭开关即可回到原路径，重启独立MCP清除测试进程状态。

本轮模型比较S为冻结S1；S2在所有32个冻结A输入上与S1实际交付字节相同，但这是正确性/兼容检查，不是S2新留出试验。原始S1源码与tokenizer均留有快照及哈希，S1冻结账本未改。

13个新单元测试覆盖普通/已知/未知JSON、来源全文、例外与观测时间、预算溢出、空来源、条件元数据拒绝、同ID冲突、完整信封计量及可见性变化。实际原生MCP与DSH profile核对授权、开关关闭、真实结果哈希、负条件及预算安全退化。

整包策略S在新任务31/56明显低于D46/56，因此S2源码仅供实验审阅，不替代D，不进入默认集成。下一步若研究选择更小的完整证据单元，必须保留与其关联的条件、反证和来源，并在新的开发/留出集验证；本轮不继续改算法。
