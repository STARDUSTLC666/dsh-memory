## 覆盖及限制

长原文、多段来源/版本、负条件和例外：Git 命令文档及 CPython 参数限制有实际对照条款。来源 commit 必需任务 8 文档×2，无记忆不能恢复过去记录的真实 commit。经验迁移 12 文档×2，当前上下文与历史文档共享可迁移规则。负迁移 8 文档×2，旧来源不能证明未来版本，全部组正确 DEFER。

多跳/冲突/时间：第六轮历史集和新 unit/native 测试保留验证；新模型主集偏文档参数规则，不等于新增复杂跨事件多跳和真实过期记忆的独立家族。复杂冲突、多跳、真实私有时序长历史仍需下一轮新来源。不能用同一批文档调参后再称留出。

32 份完整文档另走现有 MdCGOS → build_db_from_md → MdConn 支持的只读 SQL → MdStore 全正文回读，71 断言通过。派生 SQLite 是可重建缓存，权威来源仍是 Markdown 图，没有新增第二套权威库。初版探针用了未支持 ORDER BY，被接口正确拒绝；改用既有支持的自然顺序，未修改产品 SQL 权限或语义，初版 DB 留存。

原生 Markdown 节点序列化会附加一个结尾 LF；真实 DSH验证同时核对原段落 SHA 和存储正文 SHA，且要求仅一个 LF 差异。原文/跨度收据未改，不能谎称下载字节与存储字节完全相同。

模型与执行：DeepSeek 官方 flash、reasoning off、每会话最多 8 请求/14 工具/120秒、每请求输出2048，重试0。统一实际工具结果上限2048 tokenizer tokens。B/D/S 内部750是项目估算，G750是冻结tokenizer计量，不把内部单位称为完全相同的模型Token。现有DeepSeek serializer不支持采样seed；顺序和数据种子固定，provider默认温度一致，模型采样不可确定重现、模型后台权重不可验证未变。
