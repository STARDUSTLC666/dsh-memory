# 算法与交付诊断设计

这是一项默认关闭的交付组件实验。G不写入Memory、不重新检索、不改变RRF、不授予权限，也不把来源声明改成已验证知识。

## 实际实验数据流

```mermaid
flowchart LR
  A[DSH请求] --> B[实验memory_recall工具]
  B --> C[绑定Principal的MdCGSecure]
  C --> D[原有lexical与RRF候选]
  D --> E[原有recall pack与预算]
  E --> F[对相同ID授权get来源]
  F --> G[B前缀 / D来源窗口 / G完整来源包]
  G --> H[Agent submit_answer]
  H --> I[独立父进程评分]
```

本轮模型路径是实验工具直连原生Secure类；原生MCP认证/租户/令牌链另以真实stdio测试。G尚未安装进原生插件测试profile，须人审后再集成。不能把该实验图称为G生产MCP链路验收。

## 三层信息与处理方式

|层次|本次处理|安全边界|
|---|---|---|
|直接事实|保留选中来源的source_document全文；普通旧节点保留完整content|不生成新摘要，不按测试答案摘句|
|事实成立的限定|原生适用条件、不适用条件、condition comment、时间/版本、来源、验证状态|只合并完全相同元数据，不删相反记录；观测窗和生效期分开|
|辅助背景|RSI trace中的导入日志/执行observations不进入来源正文投影；正文自带背景仍保留|没有可信片段边界时，不把背景按关键词猜删|

因此G是保守的整包策略，没有宣称已解决任意长正文的安全语义压缩。查询和facts参数不会改变候选排序或去掉看似不适用的反证。必要内容超预算时交付零部分事实并返回INCOMPLETE，避免只留下肯定句、删掉否定条件。

来源原文、source hash、trace hash、metadata hash、字符span用于逐次核验；来源stable ID和receipt保持可追溯。仅同ID、同完整指纹的重复出现可合并，同ID不同版本则退让。不能合并不同来源但文字相同的记录。

原生time_window在add源码中是观测时间窗，不是自动expiry。G保留其数值并使用observation_time_window标签；真实effective_from/effective_until、believed_at、version等独立保留。这是表达原有含义，不是延长知识有效期。

## 预算与退让

enabled=True要求调用方注入模型文本计数器，预算计算整份工具JSON而非只有正文。本次为固定官方V4.1 tokenizer；API usage另作计费统计。控制信封都放不下时明确报错，不能声称0预算仍完整输出；其余溢出返回INCOMPLETE/DEFER和body-free诊断。

COMPLETE_SOURCE_BUNDLE表示所选来源整包交付，不保证候选召回充分或最终推断正确。没有检索到关键节点、身份不允许读取、源文档本来缺事实时，交付组件不能凭空补证据；实验Agent按同一提示词执行DEFER。当前接口输入必须来自MdCGSecure/原生MCP已授权读，不可用原始图绕过该前置约束。

## 可观察指标

|阶段|记录|可以判断什么|
|---|---|---|
|检索|授权候选ID、查询hash、候选顺序|目标是否进入候选|
|pack|选中ID、原生truncated/skipped|是否因top-k或装包丢失|
|来源投影|trace/source/metadata hash及span|交付是否忠于已有来源|
|交付|最终ID、实际固定tokenizer计数、预算、INCOMPLETE及原因|是否发生显式退让或隐式丢失|
|Agent|提交值、引用ID、最终独立评分|引用声明与最终输出是否一致|

正文/条件语义覆盖由独立的合成A fixture分析器核对，结果是研究代理指标；普通G诊断不复制正文、凭据或条件值。原始合成工具响应和DSH轨迹单独保存在实验目录。没有新增生产日志或第二套权威Memory数据库。

引用ID/解释是声明，不能作为内部注意力的证明。外部评分可证实提交值错误；G留出有解释给出正确版本标签、answer却填写另一标签的反例，必须按最终动作判失败。

## Oracle控制的修复边界

原E只摘A原句和部分元数据，漏了A的项目范围，并错误呈现观测窗含义；原句覆盖100%仍不足以称为完整Oracle。E2把A原有recorded_scope及观测/生效时间区分补齐，未读B隐藏答案、未改原分数。E2是主实验解封后的诊断，不用于G调参或宣称新独立泛化。下一轮若要验证单个字段贡献，应预先冻结字段消融与新任务。
