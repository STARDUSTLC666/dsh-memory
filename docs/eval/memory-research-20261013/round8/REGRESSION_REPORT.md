## 保留的失败与修复过程

1. 第一份研究全回归继承实验 profile 的 `MDCG_SLEEP=0`，使 sleep 自身守卫失败。只修正回归驱动环境，不改产品/模型实验配置/断言；完整原始失败保留，后续 329/329。
2. 第一份 TypeScript 运行落到 Windows 的 python 别名，退出 9009。仅为测试环境指定已存在的解释器和依赖，后续 148 PASS、0 FAIL、1 SKIP；未安装/改写系统 Python。
3. 最新主干首轮 329/334、4 SKIP：四个跨 Rust 断言因新 worktree 尚未构建本地二进制而失败；第五个 A11 以原始 CRLF 读源码却按 LF 字符串检查。神经检索实现和该守卫当时均与上游一致。离线构建 Rust；守卫只改为标准换行读取，保留原 staticmethod 断言，并新增 LF/CRLF 正向及删除装饰器负向控制。原有变异测试通过，再跑完整回归，不删/跳过/放宽语义断言。
4. 新增主干 DSH 工程 smoke 首次缺少 agentDefaultModel 服务而未进入模型；补齐独立 profile 后重新开新目录，失败日志保留。主干兼容脚本首次误用不存在的 revoke_token API，改为项目已有 revoke 后使用新目录重跑；不影响产品或 144 次模型实验。
