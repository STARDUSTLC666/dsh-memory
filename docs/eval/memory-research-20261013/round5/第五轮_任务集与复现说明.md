# 第五轮任务集、数据边界与复现说明

本轮使用可公开复现的 Python 微型开发任务，检验 Memory 数据流。它们不是公开 Benchmark 的既有成绩，也不是完成真实仓库 Issue 的证据。六个家族只有六个统计簇；同家族的两个实例、两次重复不能当作四个独立任务家族。

## 三类任务

|类别|家族|过去会话提供什么|当前会话需要做什么|成功标准|
|---|---|---|---|---|
|记忆必需|routing-registry|三个别名到不透明路由字符串的映射及默认路由|实现批量解析或按路由计数|精确使用本项目 A 阶段的映射，满足未知别名、顺序、零计数等公开约定|
|记忆必需|retention-policy|本项目三个等级的 TTL 秒数和到期边界规则|生成到期列表及下一期限，或保留置顶记录|精确使用 A 阶段 TTL；未知等级仍拒绝；满足边界和所有权约定|
|经验迁移|interval-ledger|半开区间、重叠/相邻合并、空区间处理|计算裁剪后的占用时长，或寻找最早可预约空档|满足裁剪、嵌套、精确容纳、无解及不修改输入等公开约定|
|经验迁移|ownership-tree|递归配置覆盖和深复制原则|为不同配置名继承默认配置，或回滚配置序列|值正确，输入不变，多个输出之间也不共享可变容器|
|负迁移|timestamp-contract|按实际 UTC 时间比较事件|按忽略偏移量的本地墙上时间选最新，或按本地日期筛选|不得套用旧 UTC 规则；满足稳定并列和顺序约定|
|负迁移|sentinel-contract|只有缺失/None 才回退默认值|新调度器对所有 falsey 值回退，并复制输出|不得套用旧 None-only 规则；正确处理禁用记录与容器所有权|

记忆必需任务的私有事实由 `make_tasks.py` 确定性生成，项目命名空间和事实不同。它们是 A 会话的测试项目约定，Python 文档并不能证明这些项目值。公共 Python 文档仅支持语言语义，A 的原始题面、真实执行轨迹、行为检查回执才是项目事实来源。D/E 的来源头分别标注 A 会话、回执 SHA256 与公共语义参考，且保留 `unverified` 状态。

经验迁移类的当前题面仍提供完整行为约定，因此无记忆也可能独立完成。它检验经验是否提供额外帮助，不能仅凭一个成功结果证明发生了经验迁移。负迁移类也明确公布新条件，正确拒绝旧经验与成功独立解题都被允许。

## 拆分和版本

原始拆分共 24 个 A→B 实例：开发 6、验证 6、旧留出 12。开发每组一次、验证每组两次。审计发现四个非私有事实家族跨拆分复用相同规格、初始代码和检查输入，所以开发/验证只作为模板重复诊断；原留出未执行。

新增 `independent-holdout-v2` 使用 12 个不同的 B 接口、代码和验收案例，复用原留出 12 次 A 会话及其事实图。12 个行为规格哈希互不相同，且不出现在旧拆分中。每组执行两次，共 144 次。新增版本在开发结果已知之后、验证结束及候选选择之前构建；不声称从研究开始就封存，也不声称未见家族泛化。

早期 v1.1 的开发结果、13 次验证结果和 1 次中断轨迹保留。v1.2 在所有组一致的工具 schema 中明确 `use/reject/defer` 枚举；随后发现新目录中的 `project_check` 指向不存在的旧文件名，216 次 v1.2 结果单列为缺少回合内反馈的诊断。v1.3-feedback 只修复这个工具入口，对 A–F 重新统一运行，并在真实工具回执中核对反馈。声明始终可选；预算、任务真值、排序、评分和反思状态不变，不同版本不混合计分。原 12 个新接口在故障版本中曾部分暴露，修复后的留出应称为统一重跑，不能冒充从未看过的封存测试。

## A–F 消融

本轮 D 是“证据交付”组，和第四轮 D 的“条件反思”组含义不同。

- A：无历史记忆。
- B：沿用第四轮实验室的 raw-experience 适配器，lexical/RRF top-4，内层 recall 前缀摘录后再截断外层 JSON。它不是正式 DSH 插件的默认配置。
- C：B 的相同候选和排序，仅增加已有机制的类型化适用条件过滤。
- D：B 的相同候选和排序，仅更改上下文组装：从同一条完整 trace 投影原 A `source_document`，保留来源、时间、条件和状态。复用既有 `evidence_delivery`，不改检索、不加反思。
- E：只用 A 身份索引和 B 公开命名空间选择适用 A 证据，采用同一交付格式。它是理想证据选择的诊断组，受生成随机性和代码能力影响，不是数学上的必然最高成功率。
- F：无任务事实的中性文字，与相同固定查询下虚拟 D 的完整工具 JSON 在固定官方 tokenizer 下等长。

所有组使用同一 DSH、模型、提示模板、公开题面和行为评分器；最多 8 次模型请求、14 次工具调用、每请求输出 2048、120 秒，reasoning/反思关闭。调用次数和实际使用 Token 允许因行为不同而变化，必须计入成本。provider 默认温度和远端模型权重未固定。

## 防止真值泄漏与错误计分

历史第四轮评分器的合成 canary 可从同进程编译对象读到隐藏常量，未见历史模型实际利用。新评分器由父进程持有期望结果，候选 worker 只接收函数输入；文件、网络、子进程操作受限制。10 项边界检查通过。它是良性开发任务的隔离措施，不是经认证的恶意 Python 沙箱。

每个公开约定都对应行为检查，所有权检查包括修改返回值后输入仍不变、多个返回记录间不串改。12 个新参考实现全通过，12 个初始实现全失败，并另存人工推导样例。评分器、参考实现、所有隐藏真值、原始轨迹全部保留。后续分析脚本可读取隐藏真值作归因，但不参与 Memory 交付、模型提示或原评分。

`source-experiences.json` 只保存 A 来源身份和哈希；事实仍来自同一个 contextual 图，不新增第二套权威记忆库。所有 B 会话只使用隔离副本，不写回共享 A 图。Oracle 不读取 B 的 `truth.json`、参考实现或私有真值账本。

## 复现入口

当前实验的环境路径及版本写入 `model-protocol.json`、`freeze-comparison-v2.json` 和 `selection-precommit-receipt.json`。Python 为独立实验 venv，DSH 使用现有 CLI 和隔离实验 profile；密钥来自现有凭据，不进入成果包。复制到其他机器时须在隔离目录配置对应路径，不应复用生产 HOME 或记忆库。

已有结果的重分析无需 API：

```powershell
$r5Python = 'E:\lingshu\work\r4-runtime-20261012\Scripts\python.exe'
$r5Root = 'E:\lingshu\work\memory-diagnosis-round5-20261012'
& $r5Python -B -X utf8 "$r5Root\comparison-v4-feedback\development\analyze.py" development
& $r5Python -B -X utf8 "$r5Root\comparison-v4-feedback\validation\analyze.py" validation
& $r5Python -B -X utf8 "$r5Root\comparison-v4-feedback\holdout\analyze.py" holdout
& $r5Python -B -X utf8 "$r5Root\analyze_stage_quality.py" "$r5Root\comparison-v4-feedback\holdout" holdout
& $r5Python -B -X utf8 "$r5Root\analyze_negative_transfer.py" "$r5Root\comparison-v4-feedback\holdout" holdout
```

原始评分也可在新的隔离目录离线重放，不用 API 或原始绝对路径。`offline_reproduce.py` 默认核对一题的六组两次结果，加 `--all` 核对全部 144 次。期望真值仍只在父评分器；原评分器和 worker 字节不变，仅把环境/路径 facade 放到新目录，绝不覆盖原始分数。

```powershell
& $r5Python -B -X utf8 "$r5Root\offline_reproduce.py" --data $r5Root --out 'E:\lingshu\work\r5-offline-independent-replay'
```

成果 ZIP 中 `round5-data` 是原实验数据，`frozen-product` 是对应公开源码与原有改动，解压后可将上述 `--data` 改为解压后的 `round5-data`。隔离 tokenizer 二进制未打包；重跑检索需自行安装 `tokenizers==0.22.1` 到新的实验 `tokenizer-runtime`，并配置本机对应的冻结仓库/DSH/Python 路径。已包含官方 tokenizer JSON、许可证和哈希。历史实验私钥、凭据和生产记忆均不进入归档。

`run_compare.mjs` 保留完成的单次结果，遇到已有未完成目录时会停止，不覆盖或偷偷重试。要独立重复模型实验，须复制冻结协议和 A 来源到新的实验目录，另行记录模型时间与 API 开销，不混入本次成绩。

冻结源码的全量回归命令为 `python scripts/run_tests.py md_cg --jobs 1`，在隔离环境由 `run_regression.py` 执行。结果为 310 项通过，另有 3 项缺少私有 DB/语料而 SKIP。SKIP 不算通过，亦不复制生产数据补齐。

回滚只需选择 B，或关闭实验 profile/移除离线实验引用；所有新行为都在显式选择的实验臂内。没有正式插件安装、默认配置切换、生产记忆修改或自动上线批准。
